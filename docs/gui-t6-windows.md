# GUI T6：使用体验（Windows）

任务卡：[tasks/GUI.md](../tasks/GUI.md) T6（用户 2026-10-17 决定）。都只改界面层，不改播放路径与保真规则。

## 1. 完成的行为

- **采样率指示灯**：状态栏右下角固定宽度的一栏（第 2 栏；用户 2026-10-17 要求从格式行移到这里），彩色圆点图标（按 DPI 生成的小图标，`SB_SETICON`）加文字，颜色与文字都写明状态（`qy_ui::text::rate_lamp`）；文字是普通的状态栏文字，读屏软件与自动化可以读取：
  | 状态 | 颜色 | 文字示例 |
  | --- | --- | --- |
  | 未播放 | 灰 | `采样率 —` |
  | 正在打开设备 | 琥珀 | `正在打开…`、`96 kHz 打开中` |
  | 设备流已按源采样率独占打开（没有重采样） | 绿 | `44.1 kHz 原生` |
  | 设备未能按曲目格式打开 | 红 | `48 kHz 未打开`（原因在状态栏与日志，例如单声道被拒；不断言是采样率本身的问题） |
  | 设备流采样率与源不同（严格路径不应出现） | 红 | `采样率不一致：源 … kHz，设备 … kHz` |

  只依据独占协商的结果，不宣称 DAC 实际运行在该采样率。
- **输出设备列表自动更新**：`qy_host_wasapi::watch::EndpointWatcher` 实现 `IMMNotificationClient`（Microsoft Learn《IMMNotificationClient interface》），设备增加、移除、状态变化与默认渲染设备变化时只投递一条窗口消息（连续的通知合并），界面线程重新枚举。选定的设备消失时保留该项并标明“（未连接）”，不自动换到别的设备；重新连接后恢复原名。注册失败时日志写明原因，并改为打开下拉框时重新枚举。
- **键盘媒体键**：播放/暂停、停止、上一首、下一首。窗口在前台时经 `WM_APPCOMMAND`（也接受单独的“播放”“暂停”命令）；另注册全局热键（`RegisterHotKey`，`MOD_NOREPEAT`），窗口不在前台时也响应，播放菜单“全局媒体键”可关闭。被其他程序占用的键在日志写明，只在窗口激活时响应。
- **记住播放列表与设置**（文件菜单，默认关闭）：开启时立即保存，退出（及注销关机）时再保存到 `%APPDATA%\QyBit\qybit-gui.cfg`；下次启动恢复播放列表顺序、选定的输出设备、窗口位置与大小（含最大化）、日志区显示与高度、列表排序箭头、全局媒体键开关。关闭时删除该文件。格式与容错见 `qy_ui::settings`：文本 `键=值`，先写临时文件再替换；未知或损坏的行忽略并在日志写明行数；不是 UTF-8 或含换行的路径不保存。**不保存**单声道复制与浮点转整数（明确开启的非严格选项，每次启动默认关闭，AGENTS §3）。
- **列表排序**：点击列标题或“列表”菜单，按添加顺序、文件名（不区分大小写）、时长（帧数与采样率按分数比较，不经浮点）、格式（容器、采样率、位数、声道）排序；同一依据再来一次反向；排序稳定；未知的值不论方向都排在最后。列标题显示箭头；加入条目或手动调整后清除。
- **调整顺序**：拖动选中的行（可多选、不连续），落点按光标在行的上半部或下半部定在该行之前或之后，最后一行以下为末尾；拖动中高亮落点行，状态栏写明“松开后移到第 N 行之前 / 列表末尾”，靠近上下边缘时滚动；Esc 或失去鼠标捕获时取消。Ctrl+↑ / Ctrl+↓（“列表”菜单的上移、下移）整体移动选中的行。落点用行高亮（`LVIS_DROPHILITED`）与状态栏文字提示，不用列表视图的插入标记。
- **播放中改变顺序**：正在播放的会话按开始时的顺序继续（与增删条目相同），播放标记跟随条目；第一次改变时日志写明“新顺序从下一次开始播放起生效”。
- **另一个虚拟桌面时不重绘**：`DwmGetWindowAttribute(DWMWA_CLOAKED)` 为真时与最小化一样暂存重绘；每 500 ms 检查一次，回到可见或窗口重新激活时补画。被其他窗口完全遮挡在 DWM 合成下没有可靠的判断方法，不处理。

## 2. 验证

- `qy-ui` 单元测试（Linux 与 Windows）：
  - `sorting_by_each_key`：各依据、反向、稳定（同为 1 秒的两首保持原顺序）、无法播放的排在最后、按添加顺序还原；
  - `moving_rows`：单行、不连续多行、到开头与末尾、越界的目标与行、原地不动时不报变化；
  - `reorder_while_playing_keeps_session_order`：会话顺序不变、播放标记跟随条目、日志只说明一次；
  - `rate_lamp_follows_negotiation`：灰、琥珀、`96 kHz 原生`，设备不接受单声道时 `48 kHz 未打开`；
  - `settings::tests`：往返、默认值、10 种损坏行逐一忽略、不可写成一行的路径跳过、不保存两个非严格选项、保存—读取—删除（含不存在时删除与非 UTF-8 内容）。
- `qybit-gui` 界面逻辑测试（Windows CI）：排序反向与箭头、加入条目后清除箭头；上移下移到顶端底端不动；选定设备消失后保留并标明、重新连接恢复原名、不自动换设备；记住与媒体键的开关；恢复设置后的下拉框、菜单勾选、箭头、日志区、媒体键与日志说明；未播放时“暂停”不做事、“播放”开始播放。
- `qy-host-wasapi`：`watch::register_and_unregister` 在 Windows CI 注册与注销端点变化通知。
- Windows CI GUI 作业（模拟设备，走真实核心、自有解码、pack 与渲染循环）：各状态下指示灯文字（跨进程读状态栏第 2 栏；就绪、播放中、单声道被拒、单声道复制）；`WM_APPCOMMAND` 播放/暂停开始播放并暂停；列表菜单排序后跨进程读回列表文字核对顺序；真实鼠标拖动第 1 行到末尾、再上移一行后读回顺序（runner 桌面不接受模拟输入时写明未运行）；投递端点变化消息后日志写明设备列表已更新；开启记住设置后退出、设置文件不含两个非严格选项、再次启动恢复同样的顺序，关闭后文件删除且退出时不再写入。截图 16–18 在 `qybit-gui-shots` 产物中。

## 3. 未运行

需要用户在真机上确认：
- 插拔 USB 音频设备、在系统声音设置中启用停用或更换默认设备时，下拉框是否随之更新；
- 窗口不在前台时键盘媒体键是否生效（以及与其他播放器同时运行时的占用提示）；
- 另一个虚拟桌面上播放、切回时界面是否补画；
- 记住设置后在多显示器或改变缩放后恢复窗口位置。

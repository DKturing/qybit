# QyBit A4：播放期间的设备硬件音量（`--volume`）

遵循根目录 AGENTS.md，接 A2。来源：2026-10-18 用户希望 qybit 不去调整系统的音量，只在用 qybit 播放时带一个音量参数，默认例如 40%。

用户的选择（2026-10-18）：

- 实现方式：播放时临时调设备硬件音量，不用软件缩放样本；
- 默认值：程序内置 40%；
- `qybit mixer`：只保留查看，去掉设置、保存与恢复（A3 撤销）。

状态：**软件部分已完成**（2026-10-18，记录见 [docs/a2-mixer.md](../docs/a2-mixer.md) §6）；验收 2（用户真机）未运行。

## 1. 做法

- `qybit --device <hw 设备> [--volume <N>%|off] [--volume-control <控制>] <文件>...`（Linux）：
  - 开始播放前，把该卡一组播放音量控制设为 N%（缺省 40%），并打开同组的静音开关；
  - 播放结束（正常结束、出错、Ctrl+C）后按相反顺序恢复原值，并读回核对；
  - `off` 不调整。
- **百分比**：与 alsamixer 相同（alsa-utils `alsamixer/volume_mapping.c`）。
  - 有 dB 信息时：dB 范围不超过 24 dB 按 dB 线性，否则按 10^(dB/60) 映射，各设备的同一百分比响度相近；取增益最接近目标的档位。
  - 没有 dB 信息时：按原始值线性。
  - `qybit mixer` 的列表用同一百分比。
- **选哪组控制**：
  - `--volume-control` 指定，如 `Headphone`、`Speaker,1`；
  - 否则按内核文档 *Standard ALSA Control Names*（`Documentation/sound/designs/control-names.rst`）的标准名称依次找 `Master`、`PCM`；
  - 都没有时，若播放方向只有一组含音量的控制就用它；
  - 仍不能确定时说明候选，不调整，照常播放。
  - 规则对所有声卡相同，不按设备型号写特例。
- **保真**：
  - 只调设备自身的硬件控制，送出的数据不变，软件增益恒为 1。
  - 设备没有可用的硬件音量时照常播放并说明原因，不以软件缩放代替。
  - 设备内部的数字衰减属于设备自身的行为（见文档）。
- **限制**：进程被强制结束时（第二次 Ctrl+C、SIGKILL、断电）来不及恢复，设备停在播放时的音量。
- **范围外**：
  - Windows 命令行（Windows 的硬件音量在 GUI T5 中，显式给 `--volume` 时报错说明）；
  - `qybit matrix`（不调整音量）；
  - Linux GUI（另卡）。

## 2. 验证

- **纯函数**：
  - 百分比与原始值的换算（对数映射、dB 线性、无 dB、静音最小档、步长），对照 alsamixer 公式独立算出的值；
  - 控制选择（Master、PCM、唯一一组、多组报错、指定名称、录音方向与没有音量的控制不可选）；
  - 命令行参数解析。
- **QEMU 虚拟机（snd-dummy）**：
  - 40% → 原始值 41（−17.70 dB）；0% 时播放前提示列出 Master；
  - 指定 Synth 100% → 0 dB；
  - 与当前相同时不写入；不存在或没有音量的控制报错；
  - 每次恢复后列表与之前完全相同；
  - 命令行 `--volume 60%` 播放后，混音器与播放前完全相同。
- **用户机器**：主板声卡不做任何设置直接播放，3.5 mm 耳机以 40% 出声；结束后 `qybit mixer` 显示 Master 回到原值。

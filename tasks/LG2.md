# LG2：Linux 图形界面的中文输入法与读屏支持

日期：2026-10-24。来源：[docs/gui-linux.md](../docs/gui-linux.md) §2 记录的两项“未实现”；用户 2026-10-24 要求做完（“第四帮我做完”）。

只改界面层（`crates/qybit-gui/src/linux/`），不涉及播放路径与保真规则。两项都要求 Linux 版仍可 musl 完全静态链接（A1）：不链接 libX11、libdbus、libatspi 等系统库。

## 1. 中文输入法（XIM）

**范围**：只有文件面板的路径栏接收文字输入，所以只有它接入输入法。播放列表等处的按键（快捷键、首字母跳转）不经过输入法。

**做法**：`src/linux/ime.rs`，用 `xim` crate 的 XIM 协议客户端（纯 Rust，经 x11rb 收发）。

- 按 `XMODIFIERS=@im=<名称>` 连接（fcitx5、ibus 都提供 XIM 接口；Wayland 桌面经 XWayland 运行时同样适用）。没有设置时不连接，按键照常直接处理。
- 输入上下文只在路径栏有输入焦点且窗口在前台时获得焦点；面板关闭、焦点移到列表或窗口失去焦点时取消焦点。
- 输入风格：输入法支持时用“光标处”（`PreeditPosition | StatusNothing`，告诉输入法路径栏光标的位置，候选框出现在光标下方，光标移动时更新）；否则用“根窗口”（`PreeditNothing`）。不实现 `PreeditCallbacks`（在路径栏内自绘预编辑文字）。
- 有焦点时按键（按下；输入法要求时也转发松开，如按 Shift 切换中英文）同步转发给输入法：提交的文字插入路径栏光标处；输入法不处理而送回的按键按普通按键处理（回车转到、退格等）。
- 连接或通信失败时停用输入法并在日志中说明原因，路径栏仍可输入键盘直接给出的字符。`xim` 在收到无法解码的文字时会 panic（库内的 `expect`），这里捕获后同样停用，不让输入法的错误数据结束程序。

## 2. 读屏支持（AT-SPI）

**做法**：界面控件描述为 AccessKit 无障碍树（`src/linux/view/a11y.rs`、`files.rs`），经 `accesskit_unix` 以 AT-SPI 提供给读屏软件（Orca 等）。`accesskit_unix` 用 zbus（纯 Rust）连接 D-Bus 会话总线。

- 只在辅助技术启用时激活（`org.a11y.Status.IsEnabled`，Orca 运行时为真）。没有会话总线或未启用时不生成树，界面照常运行，没有额外开销。
- 每次重绘后生成树，与上次送出的比较，只送变化的节点。
- 读屏软件请求的动作转为界面线程的消息，由视图按控件的语义执行，与鼠标、键盘的同一操作走同一套逻辑（发出相同的命令）。

| 控件 | 角色 | 名称 / 值 / 状态 | 动作 |
| --- | --- | --- | --- |
| 窗口 | 窗口 | QyBit | |
| 菜单栏、各菜单 | 菜单栏、菜单项（有弹出菜单，展开状态） | 文件(F) … 帮助(H) | 点击：打开 / 关闭 |
| 弹出菜单的条目 | 菜单项；可勾选的为勾选菜单项 | 文字、快捷键、勾选状态 | 点击：执行命令 |
| 按钮行 | 工具栏中的按钮 | 播放（随状态为暂停 / 继续）、停止、上一首、下一首、添加文件… | 点击 |
| 设备下拉框 | 组合框；打开时含列表框与选项 | 名称“输出设备”，值为当前设备；选项的选中状态 | 点击、展开、收起；选项点击：选择 |
| 两个选项 | 复选框 | 文字、勾选状态 | 点击：切换 |
| 格式行、音量说明 | 标签 | 文字 | |
| 音量、进度条 | 滑块 | 百分比（进度条 0–100，步长 1）；未播放或没有硬件音量时不可用 | 设置值、增加、减少（进度条 1%，音量 5%） |
| 播放列表 | 列表框（可多选）及各行 | 行名为“正在播放 / 已暂停：序号，文件，时长，格式”；选中状态、位置 | 点击、获得焦点：选中该行 |
| 日志 | 日志及每行文字 | | |
| 状态栏 | 状态栏及三段文字 | 播放状态、保真状态、采样率指示灯 | |
| 关于 | 对话框（模态） | 文字、确定按钮 | 确定：关闭 |
| 文件面板 | 对话框（模态） | 路径栏（文字输入框：文字与光标位置可读）、转到 / 上一级 / 主目录 / 根目录、显示所有文件、当前目录的列表（行名含“文件夹”或大小）、说明、添加 / 取消 | 按钮点击；路径栏获得焦点、设置文字；行点击：选中 |

键盘焦点：播放列表的焦点行或日志；菜单打开时为菜单或悬停的条目；下拉框打开时为悬停的设备；对话框中为路径栏、焦点行或确定按钮。

**未覆盖**：列标题与排序箭头、列宽拖动、列表行的拖动排序（读屏软件可用“列表”菜单的上移 / 下移与排序代替）；日志各行没有屏幕位置；进度条按百分比表示，不是时间（时间在状态栏第一段）。

**构建特性**：`qybit-gui` 的 `a11y` 特性（默认开启）带入 `accesskit_unix` 与 zbus；关闭时（`--no-default-features`）不连接 D-Bus，读屏软件读不到控件，其余照常。无障碍树本身（`accesskit` 数据结构，只依赖 `uuid`）不受特性影响，单元测试总是运行。

## 3. 依赖（版本锁定）

| crate | 版本 | 许可 | 用途 |
| --- | --- | --- | --- |
| `xim` | =0.5.0（`x11rb-client`） | MIT | XIM 客户端；带入 `xim-parser`、`xim-ctext`、`encoding_rs`、`ahash`、`hashbrown`，x11rb 只用已有版本、不启用 `allow-unsafe-code` |
| `accesskit` | =0.25.1 | MIT OR Apache-2.0 | 无障碍树的数据结构 |

`accesskit_unix` 在它自己的线程中运行 D-Bus 事件循环；没有会话总线时该线程直接结束。

## 5. 顺带修正

启动时日志区为空：`App::initial` 先生成日志内容、后排“全局媒体键”操作，前端执行后者时写入的说明随即被（之前生成的）日志内容覆盖，直到下一条日志才出现。改为把全局媒体键排在日志之后；`restore_applies_saved_settings` 测试核对顺序（改动前失败）。Windows 前端共用同一逻辑，一并修正。

## 6. 用户步骤（真机，未运行）

1. 输入法：在已配置 fcitx5 或 ibus 的桌面（`echo $XMODIFIERS` 应为 `@im=fcitx` 或 `@im=ibus`）运行 `QYBIT_GUI_TRACE=1 ./qybit-gui 2>&1 | tee gui.txt`，标准错误应有“输入法：已连接 …（光标处）”。打开“添加文件…”，按 Tab 或点击路径栏，切换到中文输入，输入一个中文目录名后回车。请核对：候选框出现在路径栏光标附近；选字后文字插入路径栏；回车进入该目录；在播放列表中按键不会弹出输入法。
2. 读屏：启动 Orca（`orca`，或在系统设置中打开屏幕阅读器）后运行 `qybit-gui`。请核对：Orca 朗读菜单（F10、方向键）、播放列表各行（上下方向键）、按钮与复选框；文件面板中路径栏的文字；用 Orca 读取状态栏的命令读出播放状态与采样率指示灯。

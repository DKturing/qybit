# QyBit GUI：极简 Rust 图形界面（Windows 优先）

遵循根目录 AGENTS.md。

**顺序**（2026-10-15 用户调整）：先在 Windows 上完成本卡（WASAPI 独占），再在 Linux 上运行（ALSA），单片机放在最后。前置条件是播放调度已在 Core（M3 T1，已完成）；GUI 只依赖桌面宿主与播放器层，不等待 M3 的实物验收。

**目标**：为现有播放器提供一个极简图形前端。GUI 只是控制与显示层，播放仍走与 CLI 相同的核心、自有解码、pack 与独占输出后端，不另建音频路径，不复制播放逻辑。

## 界面（参考 foobar2000 默认界面的布局与交互）

只借鉴布局与操作习惯，不使用其名称、图标或外观资源。

- **工具栏**：播放、暂停、停止、上一首、下一首；输出设备下拉框（列出可用端点，选定后用于下一次打开设备）。
- **播放列表**（表格）：正在播放标记、序号、文件名、时长、格式（如 `FLAC 44.1 kHz 16 位 2 声道`）。双击播放该曲；添加文件 / 添加文件夹；拖放文件或文件夹到列表；Delete 移除选中项；按列表顺序播放。
- **状态栏**：当前曲目源格式 → 设备格式与独占协商结果；已播放 / 总时长（只显示，不可拖动定位）；欠载、丢帧与错误计数；保真状态（严格路径完整 / 已改变 / 有欠载或错误）。
- **选项**：单声道复制到左右两路（tasks/O1.md），默认关闭；开启后状态栏与报告标为“已改变”。
- **不做**：音量（软件增益恒为 1）、均衡与任何 DSP、重采样、共享模式退回、媒体库、标签编辑、封面、歌词、皮肤、随机播放；播放列表与设置的保存本卡不做。

AGENTS 中 M0 不做的交互设备选择与拖放，在本卡只对 GUI 放开；CLI 不变。

**待用户决定**：拖动进度条定位（seek）需要核心与解码器支持定位（WAV 按帧计算偏移；FLAC 依 SEEKTABLE 或按帧同步扫描，RFC 9639），属于核心能力，另立任务卡；建议 GUI 基本可用后再做。

## T1：技术选型（已完成：选用 Slint，见 docs/gui-t1-selection.md）

- 纯 Rust，不嵌入 WebView、不依赖 Node/Python；候选 egui/eframe、iced、slint，按以下标准比较后选定一个并记录理由：Windows 支持（首要）、Linux 支持、表格/列表控件、文件拖放、系统文件对话框（可用 rfd 等成熟 crate）、二进制大小、依赖数量与许可证、是否需要系统运行库、空闲 CPU 占用。
- 依赖锁定版本，新增依赖说明用途。

验收：选型记录写入 docs，附各候选最小样例（含一个列表与一个按钮）在 Windows 上的构建结果：release 大小、全新编译时间、空闲 CPU（窗口打开不操作 30 秒的进程 CPU 时间）。

## T2：播放控制与线程模型

- 播放器层（`qy-player`）的控制扩展为：停止、暂停/恢复、上一首、下一首、跳到第 k 首（引擎已有对应操作）；CLI 与 GUI 共用，不另写播放逻辑。
- 新建 `qy-gui`（二进制 `qybit-gui`，Windows 使用 GUI 子系统，不弹控制台）；播放驱动在独立生产线程运行，渲染线程规则不变（不解码、不 pack、不分配、不阻塞）。
- GUI 线程只发送控制命令并读取原子计数与报告快照；不得持有或阻塞音频队列，不得在界面帧回调中做文件 I/O 或解码（读取时长与格式的文件头解析也在后台线程）。
- 停止/换曲沿用核心的代次规则，旧代次结果不得显示为当前状态。

验收：模拟后端下自动测试控制命令序列（开始、暂停、恢复、停止、连续切换、跳曲、设备失效）与状态一致；界面线程卡顿注入（人为延迟 1 秒）不导致欠载。

## T3：显示与报告

- 文字区分：源格式、请求格式、协商结果（含描述类型与 HRESULT）、可查询参数。不显示未经证实的“bit-perfect”。
- 欠载、丢帧、输出错误实时显示，且该次播放不再标示为完整保真。
- 设备不支持格式或独占打开失败时给出明确错误，不提供“改用共享模式/重采样”的选项。

验收：各状态的界面截图与对应报告字段一致；Windows 真机运行一次并记录（需用户执行）。Linux 运行在 Linux 阶段完成，届时补记；未运行的平台明确标记。

## T4：Windows 发布构建

- CI 产出 release 版 `qybit-gui.exe` 与 `qybit.exe`（单文件，无安装程序），作为构建产物上传。
- 记录大小与所需的系统组件（不应需要额外运行库）。

验收：CI 产物可下载；用户在 Windows 上直接运行。

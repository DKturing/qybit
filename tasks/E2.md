# QyBit E2：应用组装入口

遵循根目录 AGENTS.md。顺序见 [tasks/FORMATS.md](FORMATS.md)“公共接口”：E1 之后。

状态：**已完成**（2026-10-18），记录见 [docs/e2-assembly.md](../docs/e2-assembly.md)。用户 2026-10-18 要求继续实施（“继续做E1 E2”）；接口见记录 §2。

**问题**：`qybit`、`qybit-gui` 与 `qy-ui` 的文件信息读取都固定使用官方解码器（`qy-codec-auto`）。插件仓库无法编出带 Lite / Full 的命令行与图形界面程序。

## 范围

- `qybit` 与 `qybit-gui` 的主体改为库（`run(...)` 一类入口），二进制只做组装；调用方传入解码器（`HostResources::with_decoder` 已支持）与文件信息读取（时长、格式、明细文字）；
- 文件筛选的扩展名、`--help` 与“关于”中的格式列表由解码器集合提供；
- 官方发行版的二进制改为调用同一入口，行为不变；
- 示例：`examples/qy-ext-demo` 组装一个带示例格式的 CLI，CI 编译并运行。

## 验收

官方二进制行为与测试不变（CLI 回归、GUI Xvfb 与 Windows 模拟核对）；示例组装程序能播放（模拟设备）并在列表中显示示例格式；X1 文档写明接入方法。

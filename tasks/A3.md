# QyBit A3：混音器状态的保存与恢复

遵循根目录 AGENTS.md，接 A2。来源：2026-10-18 用户希望 qybit 自己保存和恢复混音器状态，不依赖 alsactl。

状态：**软件部分已完成**（2026-10-18，记录见 [docs/a2-mixer.md](../docs/a2-mixer.md) §7）；验收 2（用户机器重启后恢复）未运行。

## 1. 做法

- **命令**：
  - `qybit mixer --device <设备> --save [--file <路径>]`：把该卡所有可写、可读的混音器元素（开关、整数、枚举）的当前值写入文本文件。
  - `qybit mixer --device <设备> --restore [--file <路径>]`：按文件写回，然后读回核对。
  - 缺省路径为 `$XDG_CONFIG_HOME/qybit/mixer-<声卡 id>.txt`，没有 `XDG_CONFIG_HOME` 时为 `$HOME/.config/qybit/…`。开机服务以 root 运行时，建议用 `--file` 指定固定路径。
- **文件格式**：UTF-8 文本，可读可改。
  - 第一行为版本行；`card` 行记录声卡 id 与名称；每个元素一行，用制表符分隔：`ctl`、序号、类型、各声道的值、元素名。
  - 枚举存项号。名称含制表符或换行的元素不保存，并在输出中列出。
  - 写入时先写临时文件再改名，不会留下写了一半的文件。
- **恢复**：
  - 按“元素名 + 序号”匹配；类型、声道数、范围、项号都核对一致才写入。
  - 不一致、找不到、只读的元素逐个列出原因并跳过，其余照常恢复。
  - 文件的声卡 id 与设备不同时拒绝，免得把一块卡的状态写到另一块卡上。
  - 文件是不可信输入：解析不得 panic，并限制行数、行长与值的个数。
- **保真**：
  - 只读写设备自身的硬件控制，与 `qybit mixer` 设置值相同；送到设备的数据不变。
  - 只在用户明确运行命令时恢复。播放时不自动恢复；开机自动恢复由用户自己配置（如 systemd 服务）。

## 2. 验证

- **纯函数单元测试**：
  - 序列化 / 解析往返；
  - 损坏输入：截断、未知类型、非数字、超限、重复行；
  - 恢复计划：类型、声道数、范围、只读、缺失、项号越界；
  - 声卡 id 不符。
- **QEMU 虚拟机（snd-dummy）**：保存 → 改动若干控制 → 恢复 → 读回与保存时一致；另一块卡（Loopback）的文件被拒绝。
- **用户机器**：保存主板声卡状态；重启后恢复，3.5 mm 耳机出声（真机，用户运行）。

## 3. 验收

1. 上述测试通过，CI 中运行。
2. 用户机器上重启后恢复有效。

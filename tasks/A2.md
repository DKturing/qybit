# QyBit A2：声卡硬件混音器（`qybit mixer`）

遵循根目录 AGENTS.md。来源：2026-10-18 用户在真机上测试 A1：

- USB 耳机播放正常；
- 主板声卡（HD-Audio）参数读回一致、无欠载，但 3.5 mm 耳机听不到声音；
- `amixer` 显示该卡的 Master 为 0%、静音。

没有桌面的系统上没有 PulseAudio / PipeWire / `alsactl restore` 打开混音器，也常常没有安装 alsa-utils。用户要求增加 `qybit mixer`。

状态：**已完成**（2026-10-18，记录见 [docs/a2-mixer.md](../docs/a2-mixer.md)）：验收 1 CI 通过；验收 2 用户真机上打开 Master 后 3.5 mm 耳机出声。

2026-10-18 用户决定：`qybit mixer` 只保留查看，去掉设置（及 A3 的保存/恢复）；播放时的音量见 [A4](A4.md)。下文中“设置”的部分为当时的设计记录。

## 1. 范围

- **只调设备自身的硬件控制**：内核驱动提供的混音器元素，如编解码器的放大器、静音开关、USB 设备的功能单元。
  - 送到设备的数据不变，软件增益仍恒为 1（AGENTS §3）。
  - 只在用户明确运行命令时改动，不自动改。
- **内核接口**：直接使用控制设备 `/dev/snd/controlC*`，与 A1 相同，不依赖 alsa-lib 或 alsa-utils。
  - 用到的 ioctl：`ELEM_LIST`、`ELEM_INFO`、`ELEM_READ`、`ELEM_WRITE`、`TLV_READ`。
  - 只列接口为 MIXER 的元素（与 amixer 的简单控制相同的范围）。
- **命令**：
  - `qybit mixer --device <hw 设备>`：列出该卡的混音器控制，按“基名 + 方向”分组（如 `Master Playback Volume` 与 `Master Playback Switch` 合为 Master）。每项给出原始值与范围、百分比、dB（设备提供 dB 信息时）、开关状态，以及枚举的当前项与可选项。
  - `qybit mixer --device <设备> <控制>[,<序号>] <值>...`：设置后读回并显示。值可以是：
    - `on` / `off`：开关；
    - `N%`：按原始范围线性换算，与 amixer 相同；
    - `NdB`：取不超过该值的最大档位，需要设备提供 dB 信息；
    - 整数：原始值；
    - 枚举项名称。
    - 控制名先按完整元素名匹配，再按基名匹配播放方向，然后匹配无方向的元素。所有声道设为同一值。
- **播放前提示**：Linux 命令行播放打开设备之前，列出该卡播放方向（含无方向）中处于关闭或最小音量的控制，并提示用 `qybit mixer` 查看。
  - 只作提示，不阻止播放，不自动修改。
  - 规则对所有声卡相同，不按控制名或设备型号写特例；所以像话筒监听这类本来就该关闭的控制也会列出，提示中写明这一点。
- 范围外：
  - 图形界面中的混音器（Linux GUI 卡另定）；
  - 保存与恢复混音器状态（alsactl 的功能）；
  - 录音方向的设置限制（可以设置，但不做专门的录音功能）。

## 2. 验证

- **纯函数单元测试**：名称分组、值解析、百分比与原始值换算（含步长）、dB TLV 解析与换算（DB_SCALE 含静音、DB_MINMAX(_MUTE)、DB_LINEAR、DB_RANGE、容器），对照 alsa-lib `tlv.c` 的规则与独立算出的参考值。
  - 例：用户机器上 Master 的 0 档为 −65.25 dB。
- **新结构体**：`snd_ctl_elem_list` 的大小与偏移对照头文件，覆盖 64 位与 32 位。
- **虚拟机（`scripts/aloop-vm.sh`）**：另加载 snd-dummy（带 TLV 的音量、录音开关、枚举）。
  - 列出控制；设置百分比、dB、原始值、开关、枚举后读回一致；
  - 越界值与只读控制明确报错；
  - 播放前提示出现。
- **用户机器**：`qybit mixer --device hw:CARD=Generic_1,DEV=0` 列出 Master 等；打开 Master 后 3.5 mm 耳机出声。

## 3. 验收

1. 上述测试通过，CI 中运行（虚拟机作业）。
2. 用户机器上主板声卡经 `qybit mixer` 打开后出声（真机，用户运行）。
